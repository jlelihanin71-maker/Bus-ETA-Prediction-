# Bus-ETA-Prediction-
Machine Learning-based Bus Estimated Time of Arrival Prediction using GPS and Logbook Data.
# Résultat à présenter
Le meilleur modèle est Random Forest : 79,14 % des prédictions dans ±30 secondes, avec une erreur absolue moyenne de 24,51 secondes. 
Le résultat vient d’une validation par groupes de trajets. Après ces essais, une nouvelle journée indépendante est nécessaire pour confirmer la méthode retenue.
# Trois fichiers à ouvrir
1- Hanine_ETA_Bus_v2.ipynb : le notebook principal à ouvrir dans Google Colab. Toute la programmation de l’étude est dedans. Les résultats enregistrés peuvent être lus sans relancer les entraînements.
2- outputs/documentation/Guide_mise_a_jour_FR.md : l’explication des données, des méthodes, des scores, des limites et des éléments à intégrer au mémoire.
3- outputs/dashboard/Hanine_ETA_Dashboard.html : le tableau de bord interactif. Télécharger le fichier et l’ouvrir dans Chrome ou Edge. Il contient les données et les graphiques. La prévisualisation Google Drive peut ne pas afficher les graphiques.
